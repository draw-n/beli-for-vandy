## About our project
Have you ever felt like you wasted a meal swipe at a Vanderbilt dining hall? Would you like to know what dishes are before you step foot in line? Do you have friends who try the new dining hall foods more often than you do? Introducing Beli for Vanderbilt: an application to see which foods are enjoyed by your friends! Like Beli, this is a reviewing application to allow users to share ratings and reviews of each Vanderbilt dining hall and individual meals. Open to any faculty, staff and student at Vanderbilt University, it is the perfect way to verify another user’s opinion before trying something new.

## Technologies
We will use MongoDB because it uses a JSON format which is highly compatible with HTTP requests/responses. Python is the language of choice because all of us have considerable experience with writing Python, so we chose FastAPI as the framework for the backend server. We will also use Angular.js (TypeScript). This is a framework none of the members have tried previously; most of us have experience with React.js, so we’d like to use this project as a chance to try something new. TypeScript is great for ensuring we stick to consistent types, so there’s no unexpected field behavior. For messaging, we all agreed that we check messages the most and the quickest, so we’ll use that as our primary form of communication. Lastly, we’ll use GitHub as our form of version control for the project, and we’ll set up tasks/statuses through a Project Kanban board.

We will be deploying the project in Vercel since it provides a free hosting service for servers as long as they remain hobbyist projects (low traffic). Vercel will automatically provide us a domain, so we won’t have to worry about connecting one. We’ll be hosting the database in MongoDB Atlas since it is also free with hobbyist projects.
